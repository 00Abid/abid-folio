07 / DOCUMENTATION

Notes, workflow & principles

Learn by building

Every topic should lead to a small lab, a command log, a short explanation and a repository where another person can reproduce the result.

Version everything useful

Keep scripts, configuration examples and documentation in Git. Never commit credentials, private keys, access tokens or real environment files.

Operate safely

Understand the impact of a command before running it. Use least-privilege access, cost alerts and teardown steps when practising in cloud accounts.
