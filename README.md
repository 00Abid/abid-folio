# Abid Khan | Cloud & DevOps Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript. The visual direction follows the uploaded conceptual-sketch / engineering-notebook reference.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. No build step or package installation is required.

## Files
- `index.html` - page content and sections
- `style.css` - responsive sketch / blueprint styling
- `script.js` - mobile navigation and simulated terminal

## Important before publishing
- Verify the email, GitHub and LinkedIn URLs.
- Confirm the education details, internship dates and role description.
- Add real repository links, screenshots and exact implementation details to projects.
- Update skill statuses as you complete hands-on work.
- Add a resume link only after placing your actual PDF in the project and linking it.
- The terminal is a browser-based simulation. It does not run commands on your computer or connect to a real Linux server.
- The AWS, Docker, CI/CD and Terraform roadmap items are learning goals, not claims of production experience.

## Deploy
You can publish this static site with GitHub Pages, Netlify or Vercel. Upload the three website files (or the folder contents) to your chosen static hosting provider.
